## 📖 Overview

**Afri-COVID** is a comprehensive COVID-19 dataset collected from hospitals in **Algeria** between **January 2020 and December 2022**. The dataset was developed to support research in **statistical modeling**, **public health**, **medical imaging**, **machine learning**, and **artificial intelligence**.

Unlike many publicly available COVID-19 datasets, **Afri-COVID** combines high-resolution chest CT images with demographic information, quantitative lesion measurements, longitudinal follow-up studies, and variant-specific statistics. The dataset provides valuable resources for epidemiological studies, medical image analysis, intelligent healthcare applications, and data-driven decision-making.

## ✨ Key Features

- Large-scale COVID-19 chest CT dataset from Algeria
- More than one million CT slices
- High-quality 16-bit DICOM images
- Multiple SARS-CoV-2 variants
- Longitudinal follow-up examinations
- Quantitative lung lesion analysis
- Demographic and clinical metadata
- Suitable for statistical analysis and AI research
- Fully anonymized patient data

## 🩺 Image Characteristics

- Chest Computed Tomography (CT)
- DICOM format (16-bit grayscale)
- Resolution: **512 × 512 pixels**
- Clinical acquisitions
- Multiple acquisition dates
- Longitudinal follow-up studies
- Quantitative lesion measurements

## 🔒 Data Privacy

All examinations were retrospectively collected and **fully anonymized** before inclusion in the dataset.

The repository contains **no personally identifiable information (PII)**.
